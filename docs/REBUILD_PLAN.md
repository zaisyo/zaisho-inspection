# 材庄 入荷検品アプリ 再設計・実装計画

開始日: 2026-10-31 / 対象: Android Chrome・GitHub Pages / 本番 main は維持

## 目的と業務フロー
1. 納品予定品番を CSV/貼り付けテキストから取り込む（受入前）。
2. 特注品など未登録分は当日の納品書の画像・OCRから候補を抽出し、人が確認して追加する。
3. 物品の QR/バーコードを第一優先で読み取り、対応表で品番へ解決する。読み取れないラベルに限り品番OCR→手動確認へフォールバック。
4. 予定数量と実績を照合し、未登録・数量超過・候補複数・コード未対応を必ず停止または要確認扱いにする。
5. 検品履歴を日時・入力方法・原コード・対象明細ID・操作者（任意）と共に保持し CSV/JSON で出力する。

## システム構造（段階移行）
- UI: capture / intake / verify / export を別モジュール化。
- 保存: IndexedDB を主記憶域（案件・明細・コード対応・イベントログ）、JSON バックアップ/復元。スキーマバージョンとマイグレーションが必須。
- コード読取: ネイティブ BarcodeDetector → ZXing（端末検証で選択）。コード内容はそのまま保持して解析結果と区別する。
- OCR: ラベルと納品書で別パイプライン。切り出し候補→向き判定→解像度判定→最小限の前処理→認識→候補照合。日本語/英数字を適材適所で使用。
- 一致判定: exact match のみ自動確定候補にできる。あいまい一致は候補として表示し要人手確認。
- 非同期: カメラを継続処理し、重いOCRは独立ワーカーで実行。中断可能・タイムアウト・二重実行防止。
- 運用: main 本番固定、作業ブランチ・PR レビュー後に反映。GitHub Pages への影響はマージ時に確認。

## P0 コード監査（2026-10-31）
ソース: main/index.html (取得した実装)。
- 単一 HTML に UI / ロジック / 保存が混在している。
- 品番OCR crop は画像の高さ22%を横幅全体で切る。写真のタップで上下方向の中心しか指定できない。
- 品番OCRは英語ワーカーを SINGLE_LINE と英大文字/数字/ハイフンに制限するため、複数行・記号や小文字・日本語併記は取りこぼす恐れがある。
- Tesseract.js v5 を CDN から読み込み、jpn+eng と eng の2ワーカーを生成する。
- 比較モードOFFでは原画像OCRは実行されない。スクリーンショットの「-5」は補正後の結果だけであり、失敗の真因は未確定。
- 検品データとバーコードマップは localStorage に置かれ、端末消去や容量制限への備えが不足。
- 読取結果の部分一致候補は明示的な人手確認を必要とする。部分一致を自動確定にしない。
- この監査はコードの静的確認であり、実機精度や速度の実測ではない。

## フェーズ・合格条件
P0: mainを壊さず分岐。現行実装、再現手順、テスト対象データを記録する。
P1: モジュール分離。QR/バーコード・手動登録・履歴・CSV出力の回帰テストを全通過。
P2: 事前明細の取り込み、数量超過抑止、原コード保存、マッピングの検証。
P3: ラベルOCR。少なくとも30種類以上のラベル/各2撮影条件を含む正解付きデータで測定。品番 exact-match率95%以上を目標とし、誤確定0件が必須。
P4: 納品書OCR。メーカー別サンプル、表の行分割・品番・数量の項目別精度を測り、誤確定0件。
P5: IndexedDB・JSON/CSVバックアップ・復元テスト・スキーマ移行テスト。
P6: Galaxy A25 実機で初回起動/連続スキャン/OCR/オフライン/復帰の試験。時間は P0 実測値と比較して合否判定。

## 運用上の原則
- AI/OCR の読み取りを「納品確認済み」と自動で扱わない。
- 機械可読コードと目視の製品品番が異なる場合は対応関係を手動検証。
- 1箱の入数と1個のスキャンを混同しない。
- 元画像と診断ログは利用者の明示的な保存操作以外でクラウド送信しない。
- スクリーンショット内の「-5」だけを根拠にOCRエンジン故障と断定しない。

## 次の実装順
1. 診断画像セットを集めて、原画像/切り出し/補正後/文字結果/時間を1組として採番。
2. OCRパイプラインを独立モジュール化し、画像寸法、crop座標、文字高さ、向き、前処理の有無、Worker初期化時間を記録。
3. OCRの性能比較を行い、効果のない補正を撤去。
4. コード照合・取り込み・保存は別PRに分割して回帰可能にする。
