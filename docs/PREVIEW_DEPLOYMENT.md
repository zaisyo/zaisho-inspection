# 独立HTTPS検証サイトの公開手順

本番URLは https://zaisyo.github.io/zaisho-inspection/ 。現行の公開元 main は変更しない。

## 安全な方針
1. 本リポジトリの開発ブランチから Actions の Development preview package で検証用ZIPを生成。
2. ZIP内に diagnostics と src が揃っていることを確認。
3. 別のプレビュー専用リポジトリ（例 zaisho-inspection-preview）を用意して、そのルートへZIP内容を展開してコミットする。
4. プレビュー専用リポジトリで GitHub Pages を有効化（公開元 main / root）。ページ公開先が本番とは異なることを確認する。
5. 公開URLが確定してから、Galaxy A25でOCRとカメラ照合を実測する。

## 注意
- 現在のGitHub連携ツールには新規リポジトリ作成・Pages設定変更用のアクションがない。このため、プレビューリポジトリ作成とPages有効化は自動実行できていない。
- 開発ブランチの内容を本番mainへマージすると本番に影響する。現段階でPRをマージしない。
- GitHub Pages のソースに認証保護はない前提で運用し、顧客の納品書や識別可能な画像を検証用公開サイトにアップロード・保存しない。
- OCRライブラリや読取ライブラリは外部CDNから初回取得する設計。安定した運用のため、最終版では依存の固定・自ホスト・オフライン動作を検討する。
- Galaxy A25での動作・速度・精度は公開後に計測する必要がある。
