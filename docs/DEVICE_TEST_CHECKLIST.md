# Galaxy A25 実機テストと開発版の安全な配布

## 公開方針
- 本番 https://zaisyo.github.io/zaisho-inspection/ は変更しない。
- 開発ブランチの GitHub Actions は inspection-development-preview というZIPアーティファクトを生成する。これは公開URLではない。
- スマホのカメラにHTTPSが必要なため、実機テストには別の安全なHTTPSプレビューホスティングが必要。正式URLを確定するまでGitHub Pagesの公開元を切り替えない。
- テストには匿名化したデータだけを用いる。

## 納品予定の取り込み
1. CSV「品番,数量,品名」と「PTEC39,2,テスト品」を入力。
2. 登録前に内容を確認し、不正数量、重複、未登録コードを拒否する。
3. 予定2個の品番を3回検品し、3回目を停止する。
4. QRの原文が品番そのものと一致しなければ自動確定しない。
5. 結果CSVをExcelで開き、日本語と数量を確認する。
6. 試験画面はリロードでデータが消えるため業務には利用しない。

## OCR
1. 匿名化済みのラベル写真を選択。
2. 品番全体を指で囲み、正解品番を入力。
3. 無補正とグレースケールの精度・時間を比較。
4. 角度、照明、撮影距離を変えて繰り返し確認。
5. 個人情報を含む診断ログや原画像は公開しない。

- OCRから検品確定画面への連携
